# Brand assets

Placeholders live here until the owners provide the real files (SPEC §16).
**Do not generate new mascot art.**

Needed from the website repo's `public/` folder or the "Brushy Bear Painters" Drive folder:

| File                                          | Use                                       |
| --------------------------------------------- | ----------------------------------------- |
| `logo.svg` (+ `logo-mark.svg`)                | Top bar, login, proposal header, PDFs     |
| `mascot.svg` or `mascot.png`                  | Login screen, empty states, proposal page |
| `favicon.ico`, `icon-192.png`, `icon-512.png` | Browser tab, PWA install icons            |

Until then, `components/shell/logo.tsx` renders a text wordmark ("Brushy Bear" in Lilita One)
with a "BB" monogram tile, and `logo-placeholder.svg` is a stand-in for the mark.
